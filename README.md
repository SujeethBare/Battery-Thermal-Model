# Battery & Motor Cooling Model

MATLAB/Simulink thermal models of an electric vehicle (Nissan Leaf class) **traction motor** and **battery pack**, used to compare **active** and **passive** cooling strategies by component temperature and the energy the cooling system consumes.

---

## Aim

- Model the heat generated by motor and battery losses, and size the coolant flow needed to remove it
- Compare active and passive cooling by temperature rise and cooling energy consumption

---

## Approach

### 1. Motor cooling
- Motor losses estimated from the difference between **electrical input power** and **mechanical output power** (copper, iron/eddy current, hysteresis, switching, friction and windage losses)
- **Coolant flow rate** sized to carry the heat away
- Motor temperature and cooling energy compared for **active** and **passive** cooling

### 2. Battery cooling
- Pack heat generation from **cell internal resistance**, **interconnection** and **bus bar** resistance, using pack power and SOC data
- Battery cooling system modeled to track **pack temperature** over time
- Temperature variation and cooling energy consumption compared for **active** and **passive** cooling

## Repository guide

| File | What it does | Works with |
|---|---|---|
| `Motor_Cool.m` | Motor cooling parameters and data import | `Mot_Cooling_Model.slx` |
| `Mot_Cooling_Model.slx` | Simulink model of the motor cooling system | `Motor_Cool.m` |
| `Batt_Cool.m` | Battery cooling parameters and data import | `Batt_Model.slx` |
| `Batt_Model.slx` | Simulink model of the battery pack cooling system | `Batt_Cool.m` |

**Data files** (keep them in the same folder):

| File | Contents |
|---|---|
| `Motorelectricalpower` | Motor electrical input power over the drive cycle |
| `Motormechanicalpower` | Motor mechanical output power over the drive cycle |
| `BatteryPackPower` | Battery pack power over the drive cycle |
| `BatteryPackSOC` | Battery pack state of charge over the drive cycle |
| `NLCellData` | Nissan Leaf cell data |

---

## How to run

Open MATLAB and set the repository folder as the current folder.

**Motor cooling**
1. Run `Motor_Cool.m`
2. Run `Mot_Cooling_Model.slx`

**Battery cooling**
1. Run `Batt_Cool.m`
2. Run `Batt_Model.slx`
